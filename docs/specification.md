# PhishGuard specification

The [PhishGuard project book](project-book.md) is the canonical system specification and course submission source. It contains the eight required chapters: background, objectives, technical requirements, STRIDE, unit tests, conclusions, UML architecture and work plan.

Current status: stages 0-8 and additional checkpoints 4a/4b completed. Python contracts, reviewed data preparation, frozen grouped splits, baseline training/evaluation, safe model persistence, pretrained comparison, external generalization audit, real-mail data refresh, separately trained baseline v2, reproduced BERT-Tiny fine-tuning, bounded controlled evasion, a separately trained augmentation defense and local inference are available. See the [contract reference](contracts.md), [dataset guide](dataset.md), [baseline report](baseline.md), [pretrained comparison](pretrained.md), [generalization audit](generalization-audit.md), [baseline refresh with limitations](baseline-refresh.md), [fine-tuned comparison](finetuned.md), [controlled evasion](controlled-evasion.md) and [augmentation defense](robustness-defense.md). The [local demo](demo.md) and [current same-cohort comparison](current-comparison.md) are implemented and checked. Stage 9 final evaluation and submission remain planned. The [stage log](stage-log.md) records completed checks and their scope.

Use the [implementation plan](implementation-plan.md) for stage order and acceptance criteria. Use the root [README](../README.md) for the capabilities and commands available in the current checkout.
